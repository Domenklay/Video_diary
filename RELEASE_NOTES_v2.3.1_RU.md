# QuietMoments v2.3.1 — Google Play Services / ручные копии

## Почему возникала ошибка

На части Android-эмуляторов Google Identity Authorization API возвращает:
`API: 17 — API is not available on this device` с вложенным
`ConnectionResult{statusCode=SERVICE_INVALID}`. Код `SERVICE_INVALID`
по документации Google означает, что установленный Google Play Services не
признаётся подлинным. Простая замена OAuth-клиента или пересборка приложения
не гарантирует исправления такого окружения.

## Что изменено

- Перед вызовом Google Identity приложение проверяет наличие, состояние и подлинность Google Play Services.
- Для ошибок `SERVICE_INVALID`, отсутствующего Authorization API и неправильных OAuth-настроек показывает разные русскоязычные объяснения.
- Экран «Мой Google аккаунт» получил отдельную кнопку **«Сохранить или восстановить ZIP вручную»**. Системный выбор документа работает без Google Identity; архив можно сохранить локально либо выбрать Google Диск, если соответствующий DocumentsProvider доступен на устройстве.
- Ошибка теперь показывается внутри карточки, а не огромным красным текстом поверх оформления.
- Автоматическое облачное сохранение прекращает попытку авторизации при неисправных Play Services; локальные записи остаются нетронутыми.
- Добавлены тесты обработки ошибок авторизации. Основные проверки резервного копирования v2.3 сохранены.

## Не путать два режима

- Автоматические копии в скрытом `appDataFolder` **по-прежнему требуют** исправных Play Services, настроенного Google OAuth и разрешения пользователя.
- Ручной экспорт/импорт использует Android Storage Access Framework. При выборе Google Диска доступ зависит от приложения Google Диск и входа в нём. При отсутствии Диска можно сохранить ZIP в локальную папку и перенести его самостоятельно.

## Безопасность при установке

Тестовая debug-сборка `com.quietmoments.universeoffline.preview204` устанавливается отдельно и не наследует данные предыдущих установок. Она не заменяет существующий дневник. Для обновления основного пакета без потери данных требуется APK, подписанный прежним стабильным ключом. Удалять старую версию не нужно.
