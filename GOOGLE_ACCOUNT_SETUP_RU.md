# Google аккаунт и резервные копии «Тихих моментов» v2.2

## Что уже предусмотрено в приложении

- **Настройки → Мой Google аккаунт → Войти через Google:** системный выбор аккаунта и согласие на доступ к закрытому хранилищу приложения в Google Диске.
- Приложение запрашивает только `drive.appdata` и стандартные `openid/email/profile`. Пароль Google в приложение не вводится. OAuth-токен в файлы не сохраняется.
- **Сохранить воспоминания в Google:** проверенный ZIP-архив дневника, фото, видео, капсул времени, анкеты, «Моей вселенной» и тем. Архив загружается в закрытую область `appDataFolder` посредством Google Drive API.
- **Мои облачные копии:** список сохранений выбранного аккаунта, скачивание, проверка, подтверждение восстановления без перезаписи уже существующих записей.
- **Автосохранение:** включается по согласию пользователя. Приложение с интервалом проверяет локальные изменения и сохраняет архив при открытом и разблокированном приложении, если разрешение Google ещё действует. Постоянной фоновой синхронизации, удаления медиа из телефона и онлайн-редактирования одной записи на нескольких устройствах **нет**.
- Пустой доступ к облаку не мешает офлайн-дневнику. Старый ручной экспорт Google Диска сохранён.

## Важная настройка Google Cloud, без которой вход не заработает

Это требуется **владельцу приложения**, даже если APK правильно собран. Невозможно самостоятельно зарегистрировать чужое Android-приложение в Google OAuth лишь через исходный код.

1. Откройте https://console.cloud.google.com/ и создайте/выберите проект «QuietMoments».
2. Раздел **APIs & Services → Library**: включите **Google Drive API**.
3. Раздел **Google Auth Platform → Branding / Audience**: заполните экран согласия OAuth, выберите тип аудитории External и, пока приложение не опубликовано, добавьте свой адрес Gmail в **Test users**. Убедитесь, что отображаемые контактные данные/политика конфиденциальности соответствуют требованиям Google.
4. Раздел **Clients → Create client → Android**: укажите:
   - Package name: `com.quietmoments.universeoffline`
   - SHA-1: **отпечаток сертификата именно стабильного ключа v2.0/v2.1/v2.2**, а не debug/preview ключа.
     **SHA-1 стабильного APK: `1D:9C:05:F4:B1:C3:54:A6:B0:A1:1F:94:65:72:43:3F:25:13:35:B9`**.
5. SHA-1 можно получить из стабильного APK с Android Build Tools:
   ```
   apksigner verify --print-certs QuietMoments_v2.2_Google_Account.apk
   ```
   В выводе ищите `Signer #1 certificate SHA-1 digest`. Альтернативно используйте `keytool -list -v -keystore ...`, не публикуя ключ и пароль.
6. На телефоне должны работать Google Play Services, нужный Google аккаунт и интернет. После настройки попробуйте «Войти через Google».
7. Для отдельной debug-версии `.preview202` нужен **второй** Android OAuth-клиент для полного debug package и его SHA-1. Для проверки на обычном телефоне удобнее подписанная стабильная версия.

Не присылайте пароль Google, закрытый ключ подписи или файлы учётной записи. Для Android OAuth-клиента используют только **публичный SHA-1** и package name.

## Где сохраняются копии

Внутри скрытой папки `appDataFolder` Google Диска. Эти архивы **не отображаются** в обычной папке «Мой диск» и в браузере Google Drive; их просматривают и восстанавливают из приложения. Не путайте с прежней функцией «Google Диск», которая открывает обычный файловый выбор Android.

## Безопасность и ограничения

- **ZIP-файлы не зашифрованы**; они закрыты от других приложений штатными правами Google Диска, но не защищены отдельным паролем. Не включайте автокопирование чувствительных данных, пока не согласны с этим ограничением.
- Облачные копии — это снимки данных, а не синхронизация отдельных изменений в реальном времени. Если использовать приложение на двух телефонах одновременно, перед восстановлением изучите, какие файлы уже есть, и создайте отдельную резервную копию.
- Вход по Google разрешает облачное хранилище; PIN в приложении по-прежнему отвечает за локальную блокировку.
- При подключении другого аккаунта необходимо сначала отключить прежний в настройках; приложение не должно отправлять файлы одного пользователя в чужой аккаунт.
- Google OAuth/Drive невозможно полностью проверить в GitHub Actions без реального OAuth-клиента, смартфона и разрешений пользователя.
