# QuietMoments v2.3 — надёжность Google-резервных копий

База: v2.2.0-google-account, пакет `com.quietmoments.universeoffline`. Питомцев нет. Существующие фото, видео, альбомы, капсулы времени, анкеты, дневниковые записи, темы и «Моя вселенная» сохранены в кодовой базе.

## Изменения

1. Вместо агрегированного признака изменений (число файлов + общая длина + дата последнего файла) используется SHA-256 по упорядоченному списку **всех файлов**. Для небольших JSON дополнительно проверяется содержимое. Это позволяет обнаружить правки старых записей, даже если самый новый файл не изменился.
2. При ручной и автоматической загрузке фиксируются состояния до экспорта, после экспорта и после отправки. Если во время передачи добавлены/изменены данные, копия не помечает эти новые изменения как уже сохранённые; при следующей проверке будет новая отправка.
3. Экран Google показывает время последней подтверждённой копии. Если во время записи появились новые изменения, показывается отдельное пояснение.
4. Ошибка обновления списка облачных копий не отменяет успешный вход в Google и не выдаёт успешную отправку за ошибку.
5. Добавлены модульные тесты для обнаружения изменений в старых файлах, изменения JSON при неизменных размере/времени и изменения в процессе загрузки.

## Ограничения и безопасность

- Google OAuth требует настроенного Google Cloud проекта, Drive API, Android OAuth-клиента с верными package name и SHA-1 сертификата. Без настройки вход не заработает, даже если APK устанавливается.
- ZIP-архивы в закрытой `appDataFolder` по-прежнему не шифруются отдельным паролем.
- Автосохранение не является двусторонней синхронизацией отдельных записей и не работает постоянно в фоне.
- **Debug preview** имеет суффикс пакета `.preview203`. Его можно установить рядом с предыдущим, но он не видит данные старой установки. Для сохранения локальных данных при обновлении основного пакета нужен APK, подписанный **тем же стабильным ключом**, что и v2.1/v2.2. Не удаляйте установленный дневник ради теста.
- Полное тестирование Google OAuth и восстановления большого архива требует физического Android-устройства с настроенным OAuth. Сборка в GitHub Actions подтверждает компиляцию и модульные тесты, а не реальную облачную авторизацию.

## Где APK

GitHub → Actions → успешный запуск **Build Android APK** для `v2.3-backup-reliability` → `QuietMoments-Universe-debug-apk`. Для основной версии нужен стабильный signing key (параметры `QM_KEYSTORE_*` из workflow); без него release-артефакт остаётся неподписанным.
