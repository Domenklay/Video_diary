# Тихие моменты v1.8.4 — Шесть новых художественных тем

Добавлено шесть оригинальных высококачественных тем, созданных по отдельным иллюстрациям:

1. **Лунный сад** (`moon_garden`) — тёмное фэнтези, луна, лилии, звёзды и золотые элементы;
2. **Цветущий луг** (`meadow`) — солнечный коттеджкор, ромашки, маки, полевые цветы и бабочки;
3. **Золотой модерн** (`art_nouveau`) — стиль ар-нуво, павлины, изумрудная орнаментика и золото;
4. **Акварельная сакура** (`sakura`) — нежные розовые оттенки, ветви сакуры, туман и японский пейзаж;
5. **Неоновая галактика** (`neon`) — тёмная неоновая палитра, планеты, сияния и космические облака;
6. **Винтажная библиотека** (`vintage`) — старинные книги, розы, свечи, пергамент и бордовый бархат.

## Встроено в приложение

- **12 тем вместо 6.** Все ранее доступные темы остались в прежнем порядке, новые отмечены в галерее.
- **Единое оформление:** при выборе темы одновременно меняются фоновая иллюстрация, цвета карточек, рамок и текста, кнопки, экран анкеты и оформление отдельного WebView-раздела «Моя вселенная».
- Новые иллюстрации поставляются в APK в формате WebP с размером **800 × 1421 px**. Их не нужно скачивать отдельно; приложение работает офлайн.
- Для темы «Цветущий луг» и «Золотой модерн» добавлено движение листьев; для «Сакуры» и «Винтажной библиотеки» — лепестков; для «Лунного сада» и «Неоновой галактики» — мерцание звёзд. Анимация отключается в настройках.
- Все старые возможности v1.8.3 сохранены: видеодневник, фото, альбомы, капсулы времени, анкета, календарь, настроение, толкования карт, нумерология и совместимость.

## Тестирование

В GitHub Actions добавлен `python3 universe/tests/theme_assets.py`, который сверяет 12 палитр и файлов, WebP-заголовки и SHA256 всех новых рисунков. Сохраняется тест `node --test universe/tests/interpretations.test.cjs` для толкований.

## Данные и обновление

Тестовый APK `preview184` имеет собственный идентификатор приложения и не удаляет старую установленную v1.8.3. **Данные не переносятся автоматически** — используйте ZIP-экспорт и импорт, не удаляя старую версию до успешной проверки переноса. PIN и обычные резервные ZIP-копии пока не шифруют содержимое. Сборка в GitHub Actions и проверка APK не заменяют запуск на LDPlayer/физическом Android.
