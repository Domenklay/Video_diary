# Тихие моменты — Мой видеодневник / Моя вселенная

Android-приложение для приватного видеодневника с локальными фото и видео, альбомами, календарём, ежедневными вопросами, статистикой настроения и разделом «Моя вселенная».

## Версия и пакеты

Первая версия с **постоянной подписью**: QuietMoments **v2.9.0**.
Приложение содержит дневник, фото/видео, альбомы, календарь, 12 иллюстрированных тем, PIN и биометрию, капсулы времени, «Мою вселенную», Google и Яндекс Диск, обычные ZIP и защищённые парольные архивы `.qmb`.

- **Stable release:** `com.quietmoments.universeoffline.stable` — *один и тот же package и подписывающий сертификат во всех будущих обновлениях*.
- **Debug preview:** отдельный пакет `com.quietmoments.universeoffline.preview290`; не заменяет stable и не получает её данные автоматически.
- Старые `preview2xx` и исходный пакет `com.quietmoments.universeoffline` не могут быть обновлены поверх новой stable из-за другого идентификатора или подписи.

## Сборка APK на GitHub

Каждый push в `main` запускает **Build Android APK**.

- При настройке четырёх закрытых GitHub Actions secrets `QM_*` workflow публикует **QuietMoments-Universe-stable-release-apk** — подписанный release APK для установки и последующих обновлений.
- До настройки секретов workflow выдаёт **unsigned release** и debug preview. **Неподписанный APK устанавливать нельзя**.
- Полные инструкции по защите постоянного ключа, Google/Yandex OAuth и переносу данных — в [SIGNING_STABLE_RELEASE_RU.md](SIGNING_STABLE_RELEASE_RU.md).

Для локальной сборки нужны Java 17, Gradle 8.9 и Android SDK 35.

## Безопасность и миграция

**Не удаляйте старую рабочую версию**, пока не экспортируете ZIP и не проверите импорт в новую stable. Изолированные приложения не делят файлы. PIN/биометрия защищают вход, но не шифруют локальные медиа; отдельное парольное шифрование доступно при экспорте `.qmb`.

Приватный ключ подписи и пароли никогда не должны публиковаться в GitHub или передаваться другим пользователям.
