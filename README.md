# Тихие моменты — Мой видеодневник / Моя вселенная

Android-приложение для приватного видеодневника с локальными фото и видео, альбомами, календарём, ежедневными вопросами, статистикой настроения и разделом «Моя вселенная».

## Версия

Текущая ветка разработки: **QuietMoments v2.7** (Android, локальный дневник и «Моя вселенная»), без питомцев.
В приложении есть Google Drive и Яндекс Диск (ручные резервные копии), тема оформления, PIN, капсулы времени, календарь, поиск воспоминаний и ручной ZIP-перенос.
Новая тестовая сборка использует пакет `com.quietmoments.universeoffline.preview270` и устанавливается отдельно от v2.6, чтобы не заменить данные старых версий.

## Сборка APK на GitHub

Каждый push в `main` запускает workflow **Build Android APK**.
Откройте вкладку **Actions** → последний успешный запуск → **Artifacts** → **QuietMoments-Universe-debug-apk**.
Скачанный ZIP содержит `app-debug.apk`.

Также можно собирать локально через Android Studio / Gradle 8.9 и Android SDK 35: `gradle :app:assembleDebug`.

## Данные и безопасность

Не удаляйте установленный предыдущий видеодневник. Данные другой версии не мигрируют автоматически; сохраните резервные копии. Тестовая сборка локальная, Firebase для неё не требуется.

Этот репозиторий будет использоваться для дальнейшей разработки и проверки сборок.
