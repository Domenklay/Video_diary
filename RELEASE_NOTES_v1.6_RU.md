# Тихие моменты v1.6 — иллюстрированный интерфейс

## Изменения

- Шесть вертикальных превью тем с оригинальными иллюстрациями, сохранены все фоны v1.5.
- Повышена видимость тематического рисунка на экранах дневника и «Моей вселенной».
- Добавлены тематические заголовки экрана видеодневника, календаря и альбомов.
- Сохранение выбранной темы; плавный переход фоновых изображений в нативном интерфейсе.
- Сохранение черновиков текста, настроения, альбома и выбранной даты при переключении вкладок в текущем сеансе (Compose SaveableStateHolder).
- В «Моей вселенной» нижние вкладки получили SVG-иконки, приближённые к нативным Material Icons.
- Добавлена упрощённая адаптивная иконка Android: дневник, месяц и цветок; детальная иллюстрация остаётся на главной странице.
- Отдельный тестовый идентификатор `com.quietmoments.universeoffline.preview16`. Предыдущая v1.5 и её файлы не затрагиваются.

## Проверка

GitHub Actions успешно собрал Debug APK. Проверены структура ZIP/APK, наличие ресурсов шести тем, AndroidManifest, подпись APK V2 и синтаксис JavaScript.
Не выполнен автоматический UI-тест на устройстве Android. Проверить в LDPlayer / телефоне: открытие всех разделов, навигацию, смену темы, сохранение черновика, запись видео и резервное копирование.

## Данные и подпись

Тестовые версии устанавливаются рядом, без переноса данных. Нельзя удалять рабочую версию до создания и проверки резервной копии. Для стабильных обновлений необходимо настроить постоянный release-ключ, описанный в SIGNING_GUIDE_RU.md.
