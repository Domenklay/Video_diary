# QuietMoments v2.8.1 — исправление сбоя при включении отпечатка

## Что исправлено

- Переключатель «Вход по биометрии» больше не сохраняет настройку немедленно: сначала проверяет PIN, затем открывает системное подтверждение отпечатка и только при успешной проверке включает биометрию.
- Проверка PIN выполняется вне основного потока интерфейса, чтобы экран не зависал.
- Обращения к датчику биометрии и вызов BiometricPrompt защищены обработкой ошибок: если телефон не поддерживает способ входа или API выдаёт ошибку, приложение показывает сообщение и оставляет возможность входа по PIN.
- Native Activity получил совместимую тему AppCompat и разрешение USE_FINGERPRINT для старых версий Android; настройки Compose, иллюстрации и «Моя вселенная» не изменены.
- Отмена системной проверки отпечатка не включает биометрию и не меняет PIN.
- Выключение биометрии по-прежнему требует правильный текущий PIN. 
- Форматы ZIP и .qmb, Google/Яндекс, фотографии и видео **не изменялись**.

## Важно

Без отчёта Android о падении невозможно назвать подтверждённую первопричину. Изменения закрывают наиболее вероятные пути необработанных ошибок в переключателе и запуске системной биометрии. Для подтверждения исправления нужна проверка на реальном телефоне.

## Установка и проверка

- Тестовый пакет: `com.quietmoments.universeoffline.preview281`, устанавливается рядом с прежним v2.8 `preview280`, не заменяет его файлы и не переносит записи автоматически. Старую установку не удаляй.
- В новой версии установи PIN; затем в поле «Текущий PIN» введи тот же PIN и включи «Вход по биометрии».
- Должно открыться системное окно подтверждения. Если отпечаток прошёл успешно, переключатель останется включён.
- Сверни приложение, вернись и проверь разблокировку по отпечатку и запасной вход по PIN.
- Если приложение всё-таки закроется, нужно короткое описание окна ошибки и Android logcat с ошибкой приложения. **Не отправляй PIN или пароль архива.**
