# QuietMoments v2.6 — Яндекс Диск

## Что реализовано

- Яндекс Диск добавлен в Настройки как самостоятельное облачное хранилище наряду с Google.
- Вход по официальному Yandex LoginSDK 3.1.3. Пароль, Client secret и OAuth-токен не сохраняются в файлы. При новом открытии страницы может потребоваться повторная авторизация.
- Доступ ограничен OAuth-правом `cloud_api:disk.app_folder` и путями `app:/` REST API. Приложение не читает обычные личные файлы Диска.
- Ручной экспорт ZIP с проверкой содержимого через действующий BackupArchive. Облачная загрузка считается успешной только если Яндекс вернул файл с ожидаемым размером.
- Просмотр копий, безопасное скачивание, контроль архивов и подтверждение восстановления без замены существующих записей. Архивы прежних версий совместимы.
- Автокопирование на Яндекс **пока не включено**: сначала следует проверить авторизацию, загрузку и восстановление на настоящем устройстве.
- Google-авторизация, работа с Google Drive appDataFolder и ручные системные ZIP-копии не изменены.

## Требования к Яндекс OAuth

В Яндекс OAuth уже зарегистрировано приложение QuietMoments с Client ID `51b8d2a4853c4d2ba4a908cebd748281` и только правом «Доступ к папке приложения на Диске». Это публичный Client ID, **не** Client secret.

Тестовая debug-сборка v2.6 имеет пакет `com.quietmoments.universeoffline.preview260` и **другую подпись**, чем v2.5 preview250. Для официального LoginSDK нужно зарегистрировать ещё одну пару package name + SHA-256 в том же Яндекс OAuth приложении. Точный SHA-256 выводится в лог GitHub Actions из готового подписанного APK. При необходимости можно добавить вторую платформенную запись Android, не удаляя прежнюю.

Если на экране авторизации будет «Invalid application», 403 или проверка подписи — проверь регистрацию точной пары пакета и SHA-256.

## Как протестировать

1. Не удаляй существующую v2.5: новая preview260 установится рядом.
2. Настройки → Яндекс Диск → Войти через Яндекс.
3. Сделай новую тестовую запись и нажми «Сохранить воспоминания в Яндекс».
4. Убедись, что архив появился в списке. Выбери его и проверь описание.
5. Для проверки восстановления используй **отдельную чистую установку или заранее сохранённую копию**, не заменяй свои текущие данные.

## Безопасность и известные ограничения

- ZIP-файлы не зашифрованы собственным паролем; хранилище имеет права папки приложения. Не отключай местную резервную копию.
- Не публикуй OAuth Client secret в скриншотах или GitHub. Если он был виден на скриншоте, перевыпусти его в Яндекс OAuth; мобильный клиент использует только Client ID.
- Яндекс может отказать в загрузке при отсутствии свободного места. Не удаляй локальные записи и ранее созданные резервные копии.
- Сборка и тесты CI не гарантируют реального входа через Яндекс на конкретном телефоне; необходима проверка пользователем.
