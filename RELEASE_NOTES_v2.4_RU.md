# QuietMoments v2.4 — безопасный перенос данных

Основа: v2.3.1 с ручным ZIP-экспортом, Google Drive через системный файловый выбор, необязательной авторизацией Google OAuth и офлайн-дневником.

## Исправления

1. **Неразрушающее восстановление «Моей вселенной».** Прежний импорт мог создать `restore.json` поверх уже существующего состояния WebView. Теперь восстановление состояния Вселенной из архива ставится в очередь только если в новой установке нет файла `snapshot.json` и уже ожидающего файла `restore.json`. Существующие данные остаются приоритетными. Диалоги восстановления явно предупреждают об этом.
2. **Предварительная проверка дат дневника.** Весь список дат импортируемого журнала проверяется ещё до копирования файлов. Повреждённый архив с неверной датой не должен приводить к частичному переносу фото.
3. **Повторяющиеся даты в архиве.** При импорте одного дня больше одного раза используется только первый элемент, уже сохранённые ответы не заменяются.
4. **PIN-блокировка после пересоздания экрана.** Состояние «PIN введён» больше не сохраняется в Android SavedState: восстановление Activity не должно автоматически разблокировать приложение.
5. **Регрессионные тесты.** Добавлена проверка всех сценариев политики безопасного восстановления «Моей вселенной». Сохраняются предыдущие тесты архива, отпечатков файлов и диагностики Google.

## Необязательный Google

Ошибка `API: 17 / SERVICE_INVALID` на LDPlayer вызвана недоступной или неподлинной службой Google Play Services. Пересборка приложения не делает её исправной. Ручное ZIP-сохранение на устройство или в папку Google Диска, если файловый провайдер доступен, продолжает работать без Google Identity.

## Перенос существующих данных

**Не удаляйте установленную версию v2.1!** У неё сертификат `CN=QuietMoments Release` с SHA-1 `1D:9C:05:F4:B1:C3:54:A6:B0:A1:1F:94:65:72:43:3F:25:13:35:B9`. APK debug v2.4 будет подписан другим сертификатом и использует отдельный пакет `com.quietmoments.universeoffline.preview240`.

Безопасный перенос на новый пакет:

1. В старой версии откройте **Настройки → Перенос воспоминаний → Сохранить ZIP** и сохраните архив в папку Downloads/Google Drive.
2. Проверьте, что архив успешно создан. Не удаляйте старую установку.
3. Установите APK v2.4 рядом со старым, откройте **Перенос воспоминаний → Выбрать ZIP** и выберите этот архив.
4. Изучите отчёт о проверке и подтвердите импорт. Откройте дневник, альбомы, капсулы и «Мою вселенную» и убедитесь, что содержимое перенесено.
5. Держите исходную установку и отдельный ZIP до полной проверки.

Для возможности установить стабильный релиз **поверх** v2.1 с сохранением приватных данных требуется исходный ключ подписи v2.1. Его нет в GitHub Actions: там release-артефакт пока неподписан. Не публикуйте пароль к Google или ключ подписи в чате/репозитории. Администратор репозитория может добавить signing key как GitHub Actions Secrets.

## Ограничения

- Google OAuth по-прежнему требует официальные Google Play Services и Android OAuth-клиент, зарегистрированный для точной пары package name + SHA-1 сертификата.
- ZIP-файлы не зашифрованы отдельным паролем. Не храните их в общедоступных папках.
- Проверки CI подтверждают компиляцию и модульные тесты, но не заменяют проверку на конкретном телефоне, особенно Android DocumentsProvider, Google OAuth и перенос большой видеотеки.
