# QuietMoments v2.8.2 — понятная подсказка при включении биометрии

В разделе «Настройки → Защита PIN-кодом» переключатель «Вход по биометрии» можно нажать даже если текущий PIN ещё не введён.

При попытке включить биометрию без PIN:
- поле «Текущий PIN» получает **красную обводку** и текст ошибки под ним;
- поле получает фокус и открывается цифровая клавиатура;
- переключатель остаётся выключенным и данные не изменяются;
- при начале ввода PIN красная обводка и подсказка исчезают.

Если введён неверный PIN, поле также подсвечивается красным и предлагает повторить ввод. При недоступной биометрии вместо молчаливой неактивной кнопки выводится пояснение.

Исправления не затрагивают PIN-проверку, хранение записей, Google/Яндекс Диск и защищённый формат .qmb.

**Тестовая сборка** `com.quietmoments.universeoffline.preview282` устанавливается рядом с прежней preview281. Локальные данные между ними автоматически не копируются. Старую версию не удалять до проверки переноса. Для проверки подсказки на новой установке сначала нужно создать PIN.
