# QuietMoments v2.5 — быстрый переход в «Мою вселенную»

## Причина задержки

Нативные вкладки (главная, дневник, настройки) используют Jetpack Compose.
«Моя вселенная» — HTML/JavaScript внутри WebView в отдельном UniverseActivity.
Раньше каждый возврат в нативную вкладку завершал UniverseActivity, разрушал WebView,
а следующий переход создавал WebView заново и загружал HTML, CSS, 12 тем и JS.

## Оптимизация

- UniverseActivity больше не закрывается при переключении в нативные вкладки. Существующий экземпляр переносится вперёд внутри task с помощью `FLAG_ACTIVITY_REORDER_TO_FRONT`; WebView и текущая страница остаются загруженными.
- Одноразовая команда переключения передаётся только в памяти процесса и считывается MainActivity в `onResume`. Переход в дневник, настройки, на главную и кнопка системного «Назад» в «Моей вселенной» продолжают работать.
- MainActivity закрывает связанный task при системном возврате из главного экрана, чтобы не показать внезапно скрытый экземпляр «Моей вселенной» из стека.
- Обновлённая тема и настройка анимации применяются без перезагрузки страницы. При возврате из анкеты обновляется профиль, но текущие поля формы не перерисовываются без фактического изменения профиля.
- Сохранили штатные `web.onPause` / `web.onResume` и уничтожение WebView при завершении Activity.
- Повторная запись полностью неизменённого JSON-снимка в файл больше не выполняет синхронизацию с диском `fsync` при загрузке страницы.
- Добавлен регрессионный тест, предотвращающий возврат к `finish()` в навигации и повторной загрузке WebView на каждом переходе.

## Что ожидать

Первое открытие «Моей вселенной» после запуска процесса может по-прежнему быть медленнее нативной вкладки.
При повторном переходе между вкладками внутри живого процесса WebView должен открываться практически сразу.
Android при нехватке памяти может уничтожить фоновой экран, и тогда следующий вход будет холодным — это нормальное поведение.

## Проверка

1. Переключиться 3–5 раз между Главная ↔ Вселенная ↔ Дневник ↔ Вселенная; сравнить с v2.4.
2. Открыть внутри «Моей вселенной» дневник снов, вернуться на Главную, снова в «Мою вселенную»: страница должна открыться на прежнем разделе.
3. Изменить оформление в Настройках и вернуться в «Мою вселенную»: новая тема должна отображаться без сброса записей.
4. Сделать запись во Вселенной, выйти, снова зайти; затем полностью закрыть и снова открыть приложение; прогресс должен сохраниться.
5. Проверить системную кнопку «Назад» с внутреннего раздела (возврат на Главную «Вселенной») и с её домашнего экрана (возврат в нативную Главную).

Важно: CI проверяет компиляцию и статические контрактные тесты, но не измеряет миллисекунды загрузки на LDPlayer. Реальное ускорение подтверждается тестом в эмуляторе.

Тестовая debug-сборка: `com.quietmoments.universeoffline.preview250`, версия 2.5.0. Существующая установка v2.1 не заменяется. Для миграции используются ручные ZIP-копии из раздела «Перенос воспоминаний». Не удаляйте старую установку.
