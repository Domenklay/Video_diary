# QuietMoments v2.8 — защита входа и переносимый зашифрованный архив

## Новые функции

1. После установки PIN в **Настройки → Защита приложения** можно включить вход по отпечатку пальца или иной доступной биометрии Android. Для включения или выключения биометрии нужно сначала подтвердить действующий PIN. При отсутствии биометрического датчика доступен обычный PIN.
2. PIN-сессия теперь **сбрасывается при уходе приложения в фон**. Проверяется весь процесс, а не только нативный экран. Если «Моя вселенная» была открыта в отдельном Activity, при возвращении из фона она перенаправит на разблокировку основного приложения, сохраняя прежнюю навигацию между разделами внутри приложения.
3. В **Настройки → Облако и копии → Создать защищённую копию** появился новый формат `.qmb`: парольно защищённый, переносимый архив с фото, видео, дневником, капсулами и «Моей вселенной».
4. Расшифровка `.qmb` сначала выполняется во временное закрытое хранилище приложения, затем архив полностью проверяется штатным `BackupArchive.inspect`. Только после подтверждения выполняется импорт. Неправильный пароль, изменение файла или усечённая копия блокируют восстановление.
5. Прежний импорт обычных `.zip` не изменён.

## Технические параметры защищённого архива

- AES-256-GCM с отдельной аутентификацией каждого блока до его записи во временный ZIP.
- 64 КиБ зашифрованный блок; 16-байтовая метка GCM на блок, обязательный завершающий аутентифицированный блок.
- PBKDF2-HMAC-SHA256 (210 000 итераций, случайная соль 16 байт). Пароль от 12 символов.
- Случайный 8-байтовый префикс nonce и счётчик блока; заголовок, счётчик и признак последнего блока включены в аутентифицируемые данные.
- Пароль не записывается в настройки или файлы; временные открытые ZIP удаляются после использования и при запуске приложения после аварийного завершения.
- При потере пароля расшифровать архив будет невозможно; **храни пароль отдельно**.

## Что НЕ зашифровано

- Локальные фото, видео и состояние «Моей вселенной» в обычном хранилище приложения. PIN и биометрия защищают только интерфейс входа, **не шифруют** эти данные.
- Уже созданные ZIP-копии в Google и Яндекс Дисках. Нынешние автоматические копии Google и ручные копии Яндекса по-прежнему используют обычный ZIP. Для безопасного хранения в облаке пока нужно создать `.qmb` и выбрать облачную папку через системное окно Android.
- Прежние локальные и облачные ZIP продолжают открываться и восстанавливаться, шифрование не включается без участия пользователя.

## Ограничения тестовой версии

- APK `com.quietmoments.universeoffline.preview280` устанавливается **рядом** с версиями `preview272`, `preview271` и прочими. Старые данные автоматически между пакетами не переносятся: сначала сохрани ZIP и импортируй в новую версию. Не удаляй предыдущие приложения до проверки.
- Для тестирования OAuth Google и Яндекса в этой тестовой сборке потребуется зарегистрировать пакет `preview280` и сертификат подписи отдельно. Для проверки PIN, отпечатка и `.qmb` это не требуется.
- Системная проверка биометрии не тестируется на устройстве GitHub Actions: нужно проверить на реальном телефоне. Показывать PIN нужно только внутри приложения. Пароль архива не отправляй в чат.

## Проверка перед основным использованием

1. На новой версии установи PIN из 6–16 цифр. Если есть настроенная биометрия Android, введи текущий PIN и включи «Вход по биометрии».
2. Сверни приложение, заблокируй телефон, вернись — должен появиться экран разблокировки. Проверь ввод PIN и, отдельно, биометрию.
3. Открой «Мою вселенную», сверни Android, вернись — сначала должна потребоваться разблокировка.
4. Создай тестовую запись. Сохрани зашифрованный `.qmb` с длинным уникальным паролем в выбранную папку Android.
5. Выбери `.qmb` и убедись, что неправильный пароль не проходит. Затем введи правильный, проверь состав архива.
6. Для полной проверки импорта используй отдельную пустую установку и не удаляй источник до проверки.
7. Убедись, что обычный `.zip` из прошлой версии открывается штатным способом.
