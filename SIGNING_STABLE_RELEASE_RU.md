# QuietMoments — постоянная подпись Android APK

## Почему новая установка

Ранние Android APK имели разные `applicationId` (например, `.preview284`) и подписи. Самый ранний пакет `com.quietmoments.universeoffline` был подписан **другим** сертификатом, оригинальный приватный ключ в проекте отсутствует.

Новая постоянная версия использует отдельный идентификатор:

**`com.quietmoments.universeoffline.stable`**

Его НЕЛЬЗЯ менять при дальнейших обновлениях. Первую стабильную установку нужно делать отдельно от всех предыдущих, затем переносить записи через резервный ZIP. Для обновления **уже установленной stable** версии нужен тот же подписывающий ключ и более высокий `versionCode`.

## Постоянная подпись

Для v2.9.0 создан отдельный RSA-4096 сертификат (срок действия до 2059 года) в защищённом PKCS12-хранилище с alias `quietmoments_release`.

Публичные отпечатки (не являются секретами):
- SHA-1: `6A:CD:0F:07:C7:E4:AB:C0:96:68:2E:5C:7B:29:0F:06:35:9B:7F:62`
- SHA-256: `67:99:10:72:F1:50:9D:71:1A:02:03:C0:0D:1F:65:1A:C2:A8:30:4A:E8:D7:C9:07:08:F1:BC:EC:65:11:31:C2`

**Критически важно сохранить приватный ключ и пароль.** Без них Android не разрешит обновлять стабильное приложение: останется только создать новую установку и вручную переносить данные.

Файлы ключа и пароль **НЕ** должны попадать в GitHub commits, issues, PR, сообщения чата, в описание приложения или общедоступную папку. Сделай две защищённые офлайн-копии ключа и храни пароль отдельно.

## Как включить автоматическую подписанную сборку в GitHub

Открой: `https://github.com/Domenklay/Video_diary/settings/secrets/actions`. В разделе **Repository secrets** создай 4 секрета:

| Секрет | Содержимое |
| --- | --- |
| `QM_KEYSTORE_B64` | Base64 от PKCS12-хранилища. При подготовке предоставляется отдельный приватный текстовый файл с этой строкой. |
| `QM_KEYSTORE_PASSWORD` | Пароль хранилища из локального файла с секретами. |
| `QM_KEY_ALIAS` | `quietmoments_release` |
| `QM_KEY_PASSWORD` | Пароль ключа. Для данного PKCS12 он совпадает с паролем хранилища. |

Ничего из этого не сохраняй в репозиторий как текстовый файл. Не делай скриншоты с секретами.

После внесения всех четырёх значений: Actions → **Build Android APK** → **Run workflow** на `main`. Сборка автоматически восстановит PKCS12 из Base64 во временном каталоге раннера, подпишет release APK и загрузит его как отдельный artifact **QuietMoments-Universe-stable-release-apk**. Пароль и ключ не должны выводиться в логи. Сборка сверяет SHA-256 с зафиксированным публичным отпечатком, чтобы случайно не переключиться на новый ключ.

Если секреты не добавлены, GitHub Actions выдаёт только **unsigned** release и отдельно тестовую debug-сборку. Unsigned release APK устанавливать нельзя.

## Подключение облаков для stable версии

Для Яндекс OAuth зарегистрируй **Android package** `com.quietmoments.universeoffline.stable` с **SHA-256** `67:99:10:72:F1:50:9D:71:1A:02:03:C0:0D:1F:65:1A:C2:A8:30:4A:E8:D7:C9:07:08:F1:BC:EC:65:11:31:C2`.

Для Google OAuth Android (Google Drive) зарегистрируй тот же package с **SHA-1** `6A:CD:0F:07:C7:E4:AB:C0:96:68:2E:5C:7B:29:0F:06:35:9B:7F:62`. Предыдущие OAuth записи удалять не нужно.

Вход в облако под личным аккаунтом сможет выполнять каждый пользователь независимо. Никакой приватный ключ подписи не должен оказаться внутри приложения или у конечных пользователей.

## Перенос личных воспоминаний

1. В текущей рабочей версии создай ZIP (или скачай собственную проверенную облачную копию); храни её отдельно от приложения.
2. Установи первый стабильный APK: он будет отдельным приложением. Не удаляй старые версии.
3. Настройки → Облако и резервные копии → ручной ZIP → импорт и проверка. Убедись, что фото, видео, календарь и «Моя вселенная» восстановились.
4. Только после проверки начинай работать в stable. В последующих версиях `versionCode` увеличивается и APK с той же подписью ставится **поверх** неё без нового импорта.

## Ограничения

Стабильная подпись решает проблему обновлений, но не заменяет проверку функций на телефоне: PIN, биометрия, архивы, облака и миграция данных требуют отдельного тестирования. Старые приложения с другими пакетами автоматически не объединятся.
